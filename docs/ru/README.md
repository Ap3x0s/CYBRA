## Бенчмарки и метрики

Частая путаница: **8 бенчмарков** — это инструменты, которые порождают
тест-кейсы и вердикты (`security_suite/common.py`, константа `TOOLS`);
**11 метрик** — формулы, которые считаются поверх этих вердиктов
(`backend/cybra/metrics.py`, константа `CATALOG`). Оба счёта верны и означают
разное.
