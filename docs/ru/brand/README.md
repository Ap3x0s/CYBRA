# Фирменные ассеты

Исходники фирменного стиля CYBRA. Только растр — эмблема объёмная, с
градиентами металла, поэтому трассировка в вектор потеряла бы блики и дала
полосы на гранях.

| Файл | Что это | Кто использует |
|---|---|---|
| `emblem-trimmed.png` | Эмблема-гексагон с кубом, без подписи. Прозрачный фон, обрезана вплотную (716×716). | `scripts/prep_brand_assets.py` → `frontend/src/assets/cybra-mark.png` |
| `emblem-full.png` | Та же эмблема вместе с надписью CYBRA под ней. Не обрезана — подпись в исходнике обкусана снизу. | нигде (хранится как исходник) |
| `wordmark.png` | Только надпись CYBRA, без эмблемы. Прозрачный фон. | `scripts/prep_brand_assets.py` → `frontend/src/assets/cybra-wordmark.png` |
| `app-icon.png` | Иконка приложения: скруглённый квадрат с эмблемой внутри. Прозрачный фон, 1254×1254. | `scripts/make_favicons.py` → favicon и иконки PWA |
| `source-logo.png` | Исходный мастер-рендер на чёрном фоне, 1254×1254. Хранится как первоисточник. | только для справки |

## Как пересобрать производные

Оба скрипта идемпотентны и читают из этой папки:

```bash
python scripts/prep_brand_assets.py   # знак и надпись для шапки
python scripts/make_favicons.py       # favicon.ico, PNG-иконки, apple-touch-icon
```

`prep_brand_assets.py` обрезает прозрачные поля и сохраняет в 3×, чтобы лого
оставалось резким на ретине. `make_favicons.py` собирает многокадровый `.ico`
и PNG разных размеров, а `apple-touch-icon.png` заливает сплошным фоном —
iOS не поддерживает прозрачность в этой иконке.

## Соглашение об именах

Строчные, через дефис, `<что>-<вариант>.png`. На файлы ссылаются по пути из
скриптов выше — переименование требует правки соответствующей константы.
